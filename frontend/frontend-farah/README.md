# Event Ticketing and Venue Booking System

## Requirements
- XAMPP (PHP 8.2+, MySQL/MariaDB, Apache)
- VS Code
- Postman (for API testing)

## Installation Instructions
1. Clone or copy this project folder into your XAMPP root directory:
   `C:\xampp\htdocs\event-ticketing-system\`
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Open your browser and go to `http://localhost/phpmyadmin`.
4. Create a database named `event_ticketing` (or match the database name defined in your attached `schema.sql`).
5. Import the attached database files (`schema.sql` and `seed.sql`) via phpMyAdmin (**Never drop or overwrite existing tables** if they already exist).
6. Access the application in your browser at:
   `http://localhost/swc3633_latest_event_booking/index.php`
